## 2026-09-20 - Memoizing Lead Filtering in Pipeline Board\n**Learning:** The CRM dashboard frequently renders a pipeline board which filters the `leads` array (O(N)) for every single `stage` (O(M)) directly during the render loop. This pattern of inline unmemoized array filtering during mapping can become a significant bottleneck.\n**Action:** Use `useMemo` and an O(1) `Map` lookup structure to build index maps ahead of time instead of re-filtering collections continuously, specifically when a codebase uses similar shadcn/ui or heavy visual component structures.
