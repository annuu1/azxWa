## 2026-08-21 - ContactsList Filter Optimization\n**Learning:** The CRM contacts list view was performing an unmemoized O(n) filter on every render, with repeated string lowercasing inside the loop. This can cause unnecessary work, especially when small unrelated state changes occur (like toggling a loading spinner on a list item).\n**Action:** Applied `useMemo` and loop-invariant code motion to prevent unnecessary recalculations.
