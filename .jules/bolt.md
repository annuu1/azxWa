## 2026-10-24 - O(N*M) Pipeline Bottleneck\n**Learning:** The CRM pipeline component (`src/features/crm/components/pipeline-board.tsx`) was iterating through the entire leads array for every single stage during each render phase using inline `.filter()`.\n**Action:** Replaced the O(N*M) rendering pattern with a single `useMemo` and `Map` lookup to achieve O(N+M) complexity, ensuring leads are safely grouped once per dependency change.
