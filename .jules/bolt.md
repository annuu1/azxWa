## 2024-09-17 - Optimize contact filtering in ContactsList\n**Learning:** The ContactsList component had inefficient search filtering due to repeated `.toLowerCase()` calls for every prop combination per contact loop. This led to O(N * 3) string conversions inside the `.filter` execution, which triggered on every component render.\n**Action:** Applied `useMemo` to cache filter results based on search parameters and pulled `searchTerm.toLowerCase()` out of the loop to run once per filter update, establishing a good pattern for list processing.
