## 2024-05-18 - Optimized Array Filters in Component Render Loops\n**Learning:** The application extensively uses `.filter` inside render loops (e.g., to group data like `leads` by `stageId` in `PipelineBoard`). With multiple stages, this scales as O(N*M), where N is leads and M is stages. This anti-pattern is highly common in the CRM modules.\n**Action:** Bolt should aggressively look for unmemoized `.filter` iterations inside component `map` rendering, and replace them with a `useMemo` backed `Map` structure that categorizes data in a single O(N) pass, enabling O(1) lookups during the render phase.
