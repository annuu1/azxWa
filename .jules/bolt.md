## 2024-05-18 - Pipeline Board Memoized Leads Grouping Map
**Learning:** In the CRM pipeline board component (`src/features/crm/components/pipeline-board.tsx`), calculating leads for each stage inside the `.map()` loop via `leads.filter()` is an O(S*L) operation on every render which is heavily inefficient. We can memoize this to an O(L) operation via grouping items into a Map using `useMemo`.
**Action:** Bolt should look for repeated `array.filter` calls within rendering blocks iterating over static column structures (like Kanban boards or Pipeline stages) and replace them with a `useMemo` grouping Map, falling back to an empty array lookup (`map.get(id) || []`).
